本项目是 [Xanerix/guoapp](http://github.com/Xanerix/guoapp) 的 iOS 重建版，针对 iOS 重新适配与维护，**只提供 iOS 版本**。安装包内置红果站源，其余站源以模块形式在 **我的 › 模块** 安装，操作见 [使用说明](#使用说明)。

> [!WARNING]
> 项目处于开发阶段，不对用户数据做担保，数据可能在版本更新时丢失。

## 功能

### 界面与外观

- **导航**：发现 / 追剧 / 我的。iPhone 用底栏，iPad 用可收起的侧栏；宽屏的子页面在侧栏右侧打开。
- **界面模式**：自动识别手机 / 平板，也可手动选定，选定后不随屏幕尺寸切换。
- **主题**：跟随系统取色，或 6 个预设色板；浅色 / 深色 / 跟随系统。

### 浏览

- **发现**：站源名旁切换站源；分类 Tab 依次为推荐 / 全部 / 各榜单 / 各题材，榜单封面标出名次。第一个 Tab 顶部大卡片显示最近看过或推荐的剧。滑到底自动加载，下拉或「刷新」重新拉取当前分类。
- **搜索**：只搜当前站源，保留最近搜索；红果有输入联想。搜索后切换站源，会自动用同一个关键词在新站源重新搜索。
- **详情**：封面模糊作底，显示集数、完结状态、分类、播放量、标签和简介；选集每组 30 集，落在续播那一集，看过的集变浅，VIP 集有标记。打开时后台预缓冲续播集。

### 播放

- **竖屏**：短剧沉浸式，上下翻页切集，左右滑快进快退，长按画面打开「播放设置」，长按左右两侧倍速播放（默认 2 倍，可在设置里改），可锁定。
- **横屏**：横屏视频竖拿时视频在上、简介 / 选集在下，转横屏自动全屏；全屏双击两侧快退 / 快进，左半屏上下滑调亮度，右半屏调音量。iPad 横屏时左边视频、右边选集栏。
- **后台播放**：开启「后台播放」后，锁屏瞬间即开始播放，黑屏继续出声，无需解锁；也支持画中画与系统媒体控制。
- **通用**：下一集提前缓冲，翻页和连播直接接上；倍速、清晰度和弹幕开关会记住。红果在线播放有弹幕，本地播放不加载。

### 追剧与记录

- **追剧**：只分追 / 不追。有新集的剧排在「有更新」并标出更新集数；可搜索、按站源筛选、多选取消。后台每 30 分钟检查一批未完结的追剧。
- **观看记录**：按今天 / 昨天 / 更早分段；可搜索、按站源筛选、多选删除，「清空」只清当前列出的记录。
- **我的**：下载概况与各项设置入口；底栏图标显示正在下载的集数。

### 下载

- 详情页「下载选集」或播放页选集栏多选（点选、拖选、全选）。
- 下载页分「下载中」「已下载」，可单集或全部暂停 / 继续 / 重试；已下载按剧显示，可播放、删除、补齐缺集。
- 每集下载完自动转成普通 mp4（红果先解密，m3u8 合成一个文件），保存为 `下载目录/剧名/第 N 集.mp4`，可以直接拷出使用。
- 旧版下载的分集保持原样，旧版合并出的文件不再列出。

### 设置与备份

- **设置**：外观、播放、弹幕、代理、关于、诊断等分组（「我的」页直接入口，下载与存储在下载页设置），改动立即保存。
- **备份**：导出 / 恢复追剧、观看记录和偏好设置（含主题色），已下载视频不受影响；旧版备份仍可导入。本地配置损坏时启动页可从备份恢复。

## 使用说明

### 首次打开

1. 逐条勾选使用条款，15 秒后可以继续。
2. 红果随安装包内置并自动安装，打开 **发现** 就能看；其他站源需要先安装模块。

### 站源模块

站源是应用访问某个网站的适配代码，打包成模块（`.zip`）单独安装、更新和卸载，应用本体不再自带站源。新增或修复站源只需更新模块，不用等应用发版。

在 **我的 › 模块** 管理（发现页切换站源的面板里也有「管理站源」）：

| 标签页 | 用途 |
| --- | --- |
| 已安装 | 开关、更新、卸载站源，点卡片查看站源会访问的域名；青空在卡片上登录账号 |
| 在线仓库 | 模块商店，逐个「安装」或「安装全部站源」，标「限制级」的是成人内容 |
| 内置 | 随安装包附带的模块（目前是红果） |
| 手动 | 「选择本地文件」安装 `.zip` 模块，或「输入下载地址」填模块 zip 的链接 |

- 只能安装模块，不能直接填网站网址；没有对应模块的网站无法添加。想要新站源可以开 Issue 建议，或按 [CONTRIBUTING.md](CONTRIBUTING.md) 自己编写社区模块。
- 模块文件由应用自己保存在数据目录的 `modules` 文件夹，不需要手动放文件。
- 卸载站源会保留它的追剧、观看记录和下载，重新安装后恢复显示。
- 手动安装的模块未经仓库收录，只装可信来源的。

### 浏览与搜索

- 点发现页顶部的站源名切换站源，切换后分类和搜索都针对当前站源；若之前已有搜索结果，会用同一关键词在新站源重新搜索。
- 分类较多时点分类栏右侧的「全部分类」按钮选择；各分类的内容和排序由站点决定。
- 不想让别人看到封面：**设置 › 外观** 打开主页的模糊封面按钮，可设为开屏自动模糊限制级或全部封面。

### 播放与下载

- 竖屏、横屏的手势见上方 [播放](#播放)；长按画面打开「播放设置」，里面有弹幕样式、小窗播放（iOS 不提供投屏）。
- **后台播放**在 **设置 › 播放** 里开启：开启后暂停视频锁屏即会自动继续播放（黑屏出声），锁屏画面交给系统媒体控制。这是锁屏后台出声的前提，关闭时锁屏会挂起播放。
- 倍速、清晰度、解码方式、手势开关在 **设置 › 播放**，弹幕字号、显示区域、屏蔽词在 **设置 › 弹幕**。
- 下载目录在 **设置 › 存储** 修改和迁移。

### 备份与迁移

**设置 › 诊断** 导出 / 恢复备份，备份包含追剧、观看记录、偏好设置和已安装站源列表，恢复后会询问是否重新安装这些站源；已下载的视频不在备份里，需要单独拷贝下载目录。

### 常见问题

- **发现页提示「还没有安装站源」**：到 **我的 › 模块 › 在线仓库** 安装。
- **某个站源加载失败或很慢**：先下拉刷新或在 **设置 › 代理** 换连接方式（自动 / 直连 / 手动代理，支持 HTTP、HTTPS、SOCKS5），再到 **我的 › 模块** 看有没有更新。
- **有声音没画面、卡顿**：在 **设置 › 播放 › 解码方式** 换成兼容方式。
- **锁屏后没有继续播放**：确认 **设置 › 播放** 里的「后台播放」已开启；关闭时 iOS 会在锁屏后挂起 App，无法后台出声。
- **反馈问题**：开 Issue 时写明应用版本（**设置 › 关于**）、设备与 iOS 版本、站源和操作步骤；播放问题附上 **设置 › 诊断 › 播放调试日记** 里复制的日志。
